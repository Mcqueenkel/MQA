⚡ Skill Hints

A support showing a red “!” gives a skill hint (discounts that skill's SP cost). Chase them early, then focus stats.

49 = Junior + Classic (the most it can be: hints are never chased in Senior year). 0 = never.
Higher = chase hint facilities harder before Senior. 1.0 = neutral.

✨ Inheritance Sparks

At career end the bot picks which sparks to keep. Set how much each spark colour is worth — 0 = ignore it, 5 = want it most. It scores every offered option and takes the highest.

⚠ Spends 30 TP per reroll. It compares the original roll against the rerolled one and keeps whichever scores higher — a reroll can never lose you a better roll.
Stops rerolling once TP would drop below this.

🎯 Goal Entry Fans

Some goal races need a minimum fan count just to enter (Champions Cup needs 12,000) — and training earns no fans. If the trainee is short as that goal approaches, this races to close the gap. Only races she can actually run (surface + distance).

Turning this off risks failing a goal the trainee couldn't enter — that ended a live Copano Rickey run 804 fans short.
